A Note From Your Professor

You already work with numbers every day. Whether you read exam results, delivery times or shop sales, you meet averages, percentiles and error rates, and you must decide whether a new process is really "faster". This document teaches you to do that with proof instead of feeling. We start with probability puzzles that fool smart people, move through distributions, sampling, tests and regression, and finish with Bayesian methods, forecasting, survival analysis, experiments and optimisation.

Be honest with yourself about one thing. Statistics is not about memorising formulas. It is about knowing which question you are really asking and how data can fool you. That is why every chapter shows a simulation: when a formula and a simulation agree, you understand it. When they disagree, you have learned something even more valuable.

You already own the Math PDF, which teaches the basics from zero (probability, Bayes, distributions, hypothesis testing, MLE, loss functions, information theory). This document does not repeat that. It goes deeper and wider, and it points back to the PDF ("see Math PDF, Pillar 3.2") when a basic idea is needed.

One rule matters more than any other: never move on until the current topic feels obvious. If a chapter feels foggy, redo its worked problems with different numbers, re-run the code and change the seed, and explain the idea aloud in three sentences. One hour a day, done honestly, is enough.

What Every Topic Contains

  1. INTUITION callout: the problem the idea solves, in everyday language.
  2. Formal definition / how it works: precise but plain, with a "Words you need" table.
  3. Worked problems with real numbers: every step, a Check and a plain-language interpretation, with real code output.
  4. The picture: a diagram, table or plot, explained fully.
  5. Connection to real work: where it shows up in analytics, data engineering, ML and operations.
  6. Applications: grouped by role, with concrete examples.
  7. COMMON MISTAKE callouts: what beginners get wrong and how to catch it.
  8. Check yourself: three short questions with answers.

Every chapter ends with a recap (with a formula table), a practice set (8 to 12 problems with answers) and a prompt pack (5 prompts to paste into an AI tutor).

Contents

  1. Probability Through Problem Solving: counting, conditional probability, Bayes and base-rate traps, expectation and variance, descriptive statistics, Simpson's paradox.
  2. Distributions in Depth: Bernoulli to Dirichlet, when to use which, chi-square/t/F, multivariate normal, LLN and Markov chains.
  3. Sampling, Estimation, Confidence Intervals and the Bootstrap: sampling bias, standard error, CLT, MLE and method of moments, CIs, bootstrap.
  4. Hypothesis Testing in Depth: z, t, paired, chi-square, ANOVA with Tukey, non-parametric tests, normality tests, power and sample size.
  5. Effect Sizes, Multiple Testing and How Data Fools You: Cohen's d, odds ratios, Bonferroni, Holm, BH-FDR, p-hacking, winner's curse.
  6. Linear Regression Deeply: OLS derivation, inference, assumptions, diagnostics, VIF, influential points, interpretation.
  7. Regularization and Model Selection: ridge, lasso, elastic net, bias-variance, AIC/BIC, cross-validation, other multivariate and smoothing tools.
  8. Generalized Linear Models: logistic, Poisson, negative binomial, link functions, deviance, odds ratios, marginal effects.
  9. Bayesian Statistics: priors, posteriors, conjugacy, credible intervals, Bayesian A/B tests, MCMC intuition, PyMC awareness.
  10. Time Series Statistics: stationarity, ACF/PACF, ARIMA/SARIMA, exponential smoothing, forecast evaluation.
  11. Survival Analysis and Mixed/Hierarchical Models: Kaplan-Meier, Cox, random effects and partial pooling.
  12. Experimental Design and Causal Basics: randomisation, confounding, difference-in-differences intuition.
  13. Optimization Techniques and Information Theory: convexity, gradient descent variants, Lagrange/KKT, linear programming with scipy, entropy refresher.
  14. Statistics Interview Bank and Common Pitfalls.
  15. Project Lab: Five Statistics Portfolio Projects

How To Study This Document

Use the five-step learning loop on every chapter:

  1. Build first. Run the code of the chapter's first section before reading the explanation. Change a number and run it again.
  2. Ask. Write down what confused you. Use the Prompt pack at the end of the chapter to ask an AI tutor those exact questions.
  3. Just-in-time theory. Read the formal part only for the confusing pieces.
  4. Rebuild. Close the document and recreate one simulation from a blank file. If you can reproduce the output, you understand it.
  5. Teach. Explain the chapter's main idea in three sentences to a colleague (or a rubber duck).

Suggested pace: one chapter per week at about one hour a day (read, code, practice set, prompt pack). Chapters 4 to 6 deserve two weeks each if you want interview-level fluency. How to use the Prompt packs: paste one into any AI assistant, replace [PASTE HERE] with your own work when asked, and always attempt the exercise before reading the answer. The practice sets contain the answers directly below each question so you can check yourself honestly.

A note on tools: all numbers in this document were produced with Python (NumPy, SciPy, matplotlib, pandas, scikit-learn). Where the library statsmodels, lifelines or PyMC would be the normal choice, the early chapters rebuild the calculation by hand so you can see inside it, and the library calls are shown but marked "not run here" if they were not executed.

Prerequisites

  • Basic Python (variables, loops, functions, lists, NumPy arrays).
  • School algebra and logarithms.
  • The learner's Math PDF, at least the Probability and Statistics chapter (Pillar 3), the Calculus chapter (derivatives, gradients) and the Linear Algebra chapter (matrices, dot product). These are referred to, not repeated.
  • Curiosity about numbers. No advanced mathematics is required.
