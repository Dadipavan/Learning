5.1 Files and Paths with pathlib

BASIC EXPLANATION
pathlib is a standard module that represents file system paths as Path objects. It is used to build paths, check files and read or write them in a way that works on any operating system.
INTUITION
A file path is an address. If you write the address by hand as a string, you must remember that Windows uses \ and Mac/Linux use /. pathlib is a small address book that does this for you. Think of a courier given a delivery address: if the address is wrong, the whole delivery fails. In Python it is the same, so we handle paths with care.

How it works

  • Path("data") / "raw" / "x.csv" builds a path. The / operator joins parts with the right separator for your computer.
  • p.name is the file name, p.stem is the name without extension, p.suffix is the extension, p.parent is the folder.
  • p.exists(), p.is_file(), p.is_dir() ask questions about the disk.
  • p.read_text(encoding="utf-8") and p.write_text(...) read or write a whole small file in one call.
  • p.read_bytes() and p.write_bytes(...) do the same for binary data (images, zip files).
  • open(p, mode, encoding=...) gives a file object. Modes: "r" read (default), "w" write (erases old content!), "a" append, "b" binary (add to the others, like "rb").
  • Always use with open(...) as f: so the file is closed even if an error happens (more in Chapter 7).
  • Always pass encoding="utf-8" for text. Without it, Python uses the computer's default, and your code may behave differently on another machine.
  • p.rglob("*.log") finds files in all sub-folders. p.glob("*.log") looks in one folder only. The older glob.glob(pattern) returns strings.
  • os is the older module (os.path.join, os.listdir, os.environ). shutil copies and deletes whole trees (shutil.copy, shutil.rmtree, shutil.move). tempfile makes temporary files and folders that clean up after themselves.
  • sys.argv is the list of command-line words. sys.argv[0] is the script name.

Problem 5.1.1 Create a temporary folder with a logs sub-folder, write two log files, then inspect and read them.

Step 1Use tempfile.TemporaryDirectory() so the folder vanishes at the end.
Step 2Build paths with /, write text, and ask for name, stem, suffix, size.
Step 3Find files with rglob and glob.glob, and read line by line with enumerate.

Predict: Before you run it, how many bytes do you think app.log has? (Hint: count letters and newline characters.)

from pathlib import Path
import tempfile, shutil, glob, os

with tempfile.TemporaryDirectory() as d:
    root = Path(d)
    (root / "logs").mkdir()
    (root / "logs" / "app.log").write_text("line1\nline2\nline3\n", encoding="utf-8")
    (root / "logs" / "old.log").write_text("x\n", encoding="utf-8")
    (root / "notes.txt").write_text("hello", encoding="utf-8")
    p = root / "logs" / "app.log"
    print(p.name, p.stem, p.suffix, p.parent.name)
    print(p.exists(), p.is_file(), p.stat().st_size)
    print(sorted(x.name for x in root.rglob("*.log")))
    print(sorted(os.path.basename(x) for x in glob.glob(str(root / "logs" / "*.log"))))
    with open(p, encoding="utf-8") as f:
        for n, line in enumerate(f, start=1):
            print(n, line.rstrip())

The fix is to check the path first (Path(x).exists()), or to catch FileNotFoundError and give a clear message (Chapter 6).

Step 2Open with mode "a" twice. The second open does not erase the first write.
Step 3Write bytes([72, 105, 255]). 72 is H, 105 is i, and 255 is not a printable ASCII letter.

Connection to the real job

Data engineers read thousands of files from folders: raw logs, daily exports, Parquet files. Pipelines list files with rglob, process them one at a time, and move finished ones with shutil.move. Think of a bank clerk working through a long stack of paper slips one at a time; the same loop-over-lines pattern applies, and for line in f is the safe way for huge files.

Applications

  • Data Analytics: open the monthly export a business user emails you.
  • Data Engineering: a nightly job lists raw/2026-11-06/*.csv, processes each file, and moves it to done/.

  • MLOps / Testing: a unit test builds a temporary folder, runs the code, and deletes everything.
COMMON MISTAKE
Opening a file with mode "w" when you meant "a". "w" erases the file at once, before you write anything. If you are unsure, write to a new file name first.
COMMON MISTAKE
Forgetting encoding="utf-8". The script works on your laptop and breaks on the server when a name like "café" appears.
COMMON MISTAKE
Reading a huge file with f.read() or readlines(). That loads everything into memory. Loop over the file object instead.

5.2 JSON

BASIC EXPLANATION
JSON is a text format for storing and exchanging structured data made of objects, arrays, strings, numbers, booleans and null. Python's json module converts between JSON text and Python dicts and lists.
INTUITION
Two programs, maybe written in different languages, need to exchange data. They need a common written language. JSON is that language: plain text, easy for humans, and every language can read it. When a shop's website asks a courier service for a delivery status, the reply is almost always JSON.

Formal definition

JSON stands for JavaScript Object Notation, but it is not tied to JavaScript. It has only a few types. Here is how they map to Python:

JSONPython
object {}dict
array []list
stringstr
numberint or float
true / falseTrue / False
nullNone

Four functions matter:

  • json.dumps(obj) turns a Python object into a JSON string. (s = string)
  • json.loads(text) turns a JSON string into Python objects.
  • json.dump(obj, file) and json.load(file) do the same with a file object.

Why "dumps" and "loads"? The s stands for string. "Dump" means "pour out into text", "load" means "read back in". Think of packing a suitcase (dumps) and unpacking it at the other end (loads).

ItemExample valueWhere it appears in the job
JSON object{"id": 7, "delivery_minutes": 20}One API reply or one log event
JSON array[{"id":1},{"id":2}]A page of results from an API
null"manager": nullA missing value in an event
JSON Linesone object per lineEvent logs in a data lake

Useful options: indent=2 (pretty print), sort_keys=True, ensure_ascii=False (keep non-English letters readable), default=function (tell it how to handle types it does not know).

Problem 5.2.3 A JSON Lines log has 3 records. Find the average delivery time, and safely read a deep key.

Step 1JSON Lines means one JSON object per line. Parse each line with json.loads.
Step 2Average = (20 + 55 + 15) / 3 = 90 / 3 = 30.0.
Step 3Use chained .get(key, {}) so a missing key gives a default, not a crash.
import json
lines = '{"id":1,"delivery_minutes":20}\n{"id":2,"delivery_minutes":55}\n{"id":3,"delivery_minutes":15}\n'
rows = [json.loads(l) for l in lines.splitlines()]
print(sum(r["delivery_minutes"] for r in rows) / len(rows))
nested = {"user": {"address": {"city": "Pune"}}}
print(nested.get("user", {}).get("address", {}).get("zip", "n/a"))
30.0
n/a
  • Answer The average is 30.0 minutes, and the missing zip safely returns "n/a".
  • Check 20 + 55 + 15 = 90, and 90 / 3 = 30. The code printed 30.0.
  • Why it matters In plain words: the average delivery took 30 minutes. But look at the 55-minute one: an average hides slow outliers, which is why you also report percentiles.

The typical wrong version: nested["user"]["address"]["zip"] would stop the program with KeyError: 'zip'. Use .get with defaults when data may be incomplete.

Python object --dumps/dump--> text (JSON) --send/save--> other system
Python object <--loads/load-- text (JSON) <--receive/read--
        dict <-> {}     list <-> []     None <-> null

Connection to the real job

APIs return JSON. Config files, MLflow metadata, notebook files, and many logs are JSON. Event data in data lakes is often JSON Lines (one record per line), because you can append and stream it. In pandas you later use pd.json_normalize for nested data.

Applications

  • Data Analytics: download JSON from a web service and flatten it into a table.
  • Data Engineering: land event data as JSON Lines, one record per line, then load it into a warehouse.
  • Machine Learning: save experiment settings and metrics as a small JSON file.
  • GenAI: requests and replies of LLM APIs are JSON.
COMMON MISTAKE
Mixing up dumps/loads (strings) with dump/load (files). The s means string.
COMMON MISTAKE
Expecting tuples, sets, dates or integer keys to survive. Sets and dates raise errors; tuples and integer keys change silently.
COMMON MISTAKE
Using data["a"]["b"]["c"] on API data. One missing key crashes the job. Use .get with defaults, or catch KeyError.

Check yourself

  1. Which function turns a JSON string into a dict? Answer: json.loads.
  2. What does None become in JSON? Answer: null.
  3. How do you save a datetime in JSON? Answer: convert to an ISO string (for example with default= and isoformat()).

5.3 CSV

BASIC EXPLANATION
CSV is a plain-text format where each line is a row and values are separated by commas. Python's csv module reads and writes it and handles quoting correctly.
INTUITION
CSV is a spreadsheet saved as text: one row per line, cells split by commas. It looks too simple to go wrong, but a city name like "Delhi, North" has a comma inside it. Splitting on commas by hand would cut it in two. The csv module handles quotes for you.

How it works

CSV means comma-separated values. Why a module and not split(",")? Because the format has rules: a cell that contains a comma, a quote or a line break must be wrapped in double quotes, and a quote inside a cell is doubled. The module knows all these rules.

ItemExample valueWhere it appears in the job
Header roworder_id,city,amountNames the columns for DictReader
Quoted cell"Delhi, North"City names, addresses, free text
Delimiter; or tabEuropean exports and .tsv files
Customer listcustomers.csvSample data for testing a program
  • csv.reader(file) gives each row as a list of strings.
  • csv.DictReader(file) uses the header row and gives each row as a dict. Best for readable code.
  • csv.writer and csv.DictWriter write rows and add quotes when needed.
  • When opening a real file for CSV, use open(path, newline="", encoding="utf-8"). The newline="" stops blank lines on Windows.
  • Everything is read as a string. You must convert: float(row["amount"]).
  • Another delimiter (like ; or tab) is set with delimiter=";".

Here we use io.StringIO, which is a fake file in memory, so the examples run without any file on disk. A real file works the same way.

Worked examples

Problem 5.3.1 Read an orders CSV with a quoted comma. Compute the total amount and the total per city.

Step 1Use DictReader. Row 3 has "Delhi, North" inside quotes, so it stays as one cell.
Step 2Convert amounts with float. Total = 250.50 + 1200 + 75.25 = 1525.75.
Step 3Use defaultdict(float) to sum per city. (A defaultdict(float) is a dict that creates 0.0 for a missing key. Chapter 4 explains it fully.)

Predict: What will rows[2]["city"] be? One cell or two?

5.4 Dates, Times and Time Zones

BASIC EXPLANATION
The datetime module represents dates, times and time zones. A datetime is naive if it has no time zone and aware if it does, and aware values are used to compare and convert times safely.
INTUITION
"9:00" means nothing until you say where. A test that starts at 9:00 in Chennai is 3:30 in the morning in London. Servers usually store time in UTC (Coordinated Universal Time, the world's reference clock), and show local time only when a person looks at it. Think of UTC as the one common ruler that every system measures against.

Words you need

daylight saving (DST)Some places move clocks forward one hour in summer
timestampSeconds since 1 Jan 1970 UTC, as one number
ISO 8601The standard text form: 2026-11-07T14:05:00+05:30

Formal definition

The datetime module has these classes:

  • date: year, month, day.
  • datetime: date plus time.
  • timedelta: a length of time (days, seconds). Subtracting two dates gives a timedelta.
  • timezone.utc: the UTC zone.
  • zoneinfo.ZoneInfo("Asia/Kolkata"): a named time zone from the standard IANA database. It knows daylight saving rules.

A datetime is naive if it has no zone (tzinfo is empty) and aware if it has one. You cannot mix them in arithmetic.

Converting text and dates: strptime(text, format) parses text; strftime(format) makes text. Common codes: %Y year, %m month, %d day, %H hour (24h), %M minute, %S second, %A weekday name, %B month name. datetime.fromisoformat(...) reads ISO 8601 text such as 2026-11-07T14:05:00+05:30.

5.5 Configuration: Environment Variables, .env Files, YAML and TOML

BASIC EXPLANATION
Configuration is the set of settings that change between environments, such as database addresses and keys. It is kept outside the code in environment variables, .env files, YAML or TOML files.
INTUITION
The same program runs on your laptop, a test server, and production. The database address is different in each. If you type the address inside the code, you must edit code for each place. Instead, keep settings outside the code and let each machine provide its own. This is like a restaurant kitchen reading the day's specials from a board instead of rewriting the recipe book.

How it works

Words you need: an environment variable is a named text value that the operating system attaches to every program it starts (like a sticky note on the program's desk). A secret is a value that must stay private, such as a password or API key.

ItemExample valueWhere it appears in the job
Env variableDB_HOST=db.internalDocker, Kubernetes, GitHub Actions
.env fileAPI_KEY=fake-key-123Your laptop during development
TOML file[db] port = 5432pyproject.toml and tool settings
YAML filedb: then port: 5432Airflow, Kubernetes, CI pipelines

Three common places for settings, from most to least specific:

  1. Environment variables: named values the operating system gives to a program. In Python: os.environ.get("NAME", "default"). os.environ["NAME"] raises KeyError if it is missing (good when the setting is required).
  2. .env file: a text file of NAME=value lines used on a developer machine. A helper library (python-dotenv) loads it into the environment. The file must be listed in .gitignore and never committed, because it often holds secrets.
  3. Config files: YAML (needs the third-party PyYAML package, not run here), TOML (tomllib is in the standard library from Python 3.11, read-only), or JSON.

Environment variables are always strings. Convert: int(os.environ.get("DB_PORT", "5432")).

5.6 Handling Archives, Temporary Files, Deprecated Time Calls and Pickle

Real data work moves compressed files around, writes scratch files, and keeps old code alive. This section covers the standard-library tools for that and two traps: datetime.utcnow() and pickle.

COMMON MISTAKE
datetime.utcnow() and datetime.utcfromtimestamp() are deprecated since Python 3.12. They return a "naive" time (no time zone attached) that looks like UTC but is easy to confuse with local time. Use datetime.now(timezone.utc), which returns an "aware" time that carries its zone. Section 5.4 explains aware versus naive.

Problem 5.6.1 Compress a CSV with gzip, bundle files in a zipfile, copy with shutil, all inside a TemporaryDirectory that deletes itself. Also show the deprecation warning.

Step 1warnings.catch_warnings(record=True) with the filter set to "always" captures the warning utcnow() raises. The category is DeprecationWarning.
Step 2Write a 4,000 byte CSV (the line pair is repeated 200 times). Copy it into a .gz file with shutil.copyfileobj, which streams in chunks, so it works for files larger than memory.
Step 3Read the gzip back in text mode ("rt"). Build a zip with ZipFile.write (a file) and writestr (text made in memory).
Step 4Leave the with block: the directory and everything in it is gone, so root.exists() is False.
import gzip, shutil, tempfile, zipfile, warnings
from datetime import datetime, timezone
from pathlib import Path
with warnings.catch_warnings(record=True) as w:
    warnings.simplefilter("always")
    datetime.utcnow()
print(w[0].category.__name__)
print(datetime.now(timezone.utc).tzinfo)
with tempfile.TemporaryDirectory() as d:
    root = Path(d)
    (root / "data.csv").write_text("id,amount\n1,10\n2,20\n" * 200)
    raw = (root / "data.csv").stat().st_size
    with open(root / "data.csv", "rb") as src, gzip.open(root / "data.csv.gz", "wb") as dst:
        shutil.copyfileobj(src, dst)
    gz = (root / "data.csv.gz").stat().st_size
    print(raw, gz, gz < raw)
    with gzip.open(root / "data.csv.gz", "rt") as f:
        print(f.readline().strip(), f.readline().strip())
    with zipfile.ZipFile(root / "bundle.zip", "w", zipfile.ZIP_DEFLATED) as z:
        z.write(root / "data.csv", arcname="data.csv")
        z.writestr("notes/readme.txt", "hello")
    with zipfile.ZipFile(root / "bundle.zip") as z:
        print(z.namelist())
        print(z.read("notes/readme.txt").decode())
    copy = shutil.copy(root / "data.csv", root / "backup.csv")
    print(Path(copy).name, sorted(p.name for p in root.iterdir()))
print(root.exists())

Pickle: convenient and dangerous

pickle saves almost any Python object to bytes and loads it back. That convenience is also the danger: unpickling can run code. An object can define __reduce__ to tell pickle "to rebuild me, call this function with these arguments", and that function can be anything. So loading a pickle from a stranger is like running their program.

Problem 5.6.2 Round-trip a dict, then show that loading a crafted pickle executes code.

Safe usepickle.loads(pickle.dumps(data)) equals the original.
AttackA class whose __reduce__ returns (print, ("...",)). Loading it calls print. Real attackers return os.system instead.
Safe alternativeJSON carries only data (dicts, lists, strings, numbers), never code.
import pickle, json
data = {"user": "ada", "scores": [1, 2, 3]}
print(pickle.loads(pickle.dumps(data)) == data)
class Evil:
    def __reduce__(self):
        return (print, ("code ran during unpickling",))
pickle.loads(pickle.dumps(Evil()))
print(json.loads(json.dumps(data)) == data)
True
code ran during unpickling
True
KEY IDEA
Only unpickle bytes you created yourself and stored where nobody else can write. For anything that crosses a trust boundary (uploads, network, shared folders) use JSON, CSV or Parquet. Chapter 13 repeats this rule in the security section.

Chapter recap

  • Use pathlib.Path and the / operator for paths; it works on every operating system.
  • Always open text files with encoding="utf-8" and use with so they close.
  • Loop over a file object line by line for big files; do not read it all at once.
  • "w" erases, "a" appends. shutil copies and deletes trees; tempfile cleans up after itself.
  • JSON maps to dict, list, str, number, bool, None. dumps/loads work on strings, dump/load on files.
  • Tuples become lists in JSON, integer keys become strings, and dates need default= or conversion.
  • The csv module handles quotes and commas; every value arrives as a string.
  • Store and compute time in UTC with aware datetimes; convert to local time only for display.
  • Do arithmetic across daylight saving changes in UTC, and time code with time.perf_counter().
  • Keep settings in environment variables or config files, never in code, and never commit .env.
