6. (easy) A leaf has G = 6, H = 5, λ = 1. What is the leaf value? Answer: −6/(5+1) = −1.

7. (medium) A split has G_L = 4, H_L = 2, G_R = −4, H_R = 2, λ = 1, γ = 1. Is it kept? Answer: gain = ½ · [16/3 + 16/3 − 0/5] − 1 = 5.333 − 1 = 4.333, which is positive, so yes.

8. (medium) Eight rows have a leaf with n = 4 rows, squared error, mean residual 2.875. What is the leaf value for λ = 10? Answer: G = 11.5, H = 4: 11.5 / (4 + 10) = 0.8214, matching Example B. The leaf was shrunk by 4/14.

9. (medium) Find the bug: a team uses the test set as the early-stopping set and reports "best test MSE 5.09". Answer: The test set chose the round, so the score is optimistic. In Example C, validation said 5.091 and an untouched test set said 5.580. Use separate validation and test sets.

10. (hard) For the asymmetric loss w(y−F)² with w = 3 when y > F, compute g, h and the first Newton leaf for a single row y = 10, F = 7. Answer: g = −2·3·(10−7) = −18, h = 6, leaf = −g/h = 3, which moves F to exactly 10 (quadratic loss, one Newton step is exact).

11. (hard, interview) Why does XGBoost use second derivatives and what does min_child_weight mean for log loss? Answer: The second derivative gives a Newton step and a closed-form leaf value and gain. min_child_weight is the minimum summed h in a leaf; for log loss h = p(1−p) ≤ 0.25, so a leaf of confidently predicted rows needs many more rows to pass the threshold than a leaf of uncertain rows.
