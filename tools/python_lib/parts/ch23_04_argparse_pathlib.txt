<h3>argparse: turning a script into a command</h3>
<p><code>argparse</code> (standard library) reads <code>sys.argv</code>, converts and validates the values, writes <code>--help</code> for you and exits with a clear message on bad input. In tests you pass a list to <code>parse_args</code> instead of reading the real command line.</p>
<div class="tablewrap"><table class="data"><thead><tr><th>Name</th><th>What it does</th><th>Minimal example</th></tr></thead><tbody>
<tr><td><code>ArgumentParser(description=...)</code></td><td>Creates the parser</td><td><code>p = argparse.ArgumentParser(prog="clean")</code></td></tr>
<tr><td>positional argument</td><td>A required value identified by position</td><td><code>p.add_argument("csv")</code></td></tr>
<tr><td>optional flag</td><td>A named value, optional by default</td><td><code>p.add_argument("--out", default="out.csv")</code></td></tr>
<tr><td><code>type=</code></td><td>Converts the text (int, float, Path, or your function)</td><td><code>p.add_argument("--n", type=int)</code></td></tr>
<tr><td><code>choices=</code></td><td>Restricts to listed values</td><td><code>choices=["csv", "json"]</code></td></tr>
<tr><td><code>required=True</code></td><td>Makes a flag mandatory</td><td><code>p.add_argument("--key", required=True)</code></td></tr>
<tr><td><code>action="store_true"</code></td><td>Boolean switch, False unless given</td><td><code>p.add_argument("--dry-run", action="store_true")</code></td></tr>
<tr><td><code>action=BooleanOptionalAction</code></td><td>Creates <code>--x</code> and <code>--no-x</code></td><td><code>action=argparse.BooleanOptionalAction</code></td></tr>
<tr><td><code>action="count"</code></td><td>Counts repeats such as <code>-vvv</code></td><td><code>p.add_argument("-v", action="count", default=0)</code></td></tr>
<tr><td><code>nargs</code></td><td>Number of values: <code>"+"</code> one or more, <code>"*"</code> zero or more, an int</td><td><code>p.add_argument("files", nargs="+")</code></td></tr>
<tr><td><code>dest</code>, <code>metavar</code></td><td>Attribute name; placeholder shown in help</td><td><code>dest="out_path", metavar="FILE"</code></td></tr>
<tr><td><code>help=</code></td><td>Text shown by <code>-h</code></td><td><code>help="output file"</code></td></tr>
<tr><td><code>add_subparsers</code></td><td>Git-style subcommands</td><td><code>sub = p.add_subparsers(dest="cmd", required=True)</code></td></tr>
<tr><td><code>set_defaults(func=...)</code></td><td>Attach the function a subcommand runs</td><td><code>s.set_defaults(func=run_train)</code></td></tr>
<tr><td><code>add_mutually_exclusive_group</code></td><td>Only one of several flags allowed</td><td><code>g = p.add_mutually_exclusive_group()</code></td></tr>
<tr><td><code>parse_args(list)</code></td><td>Parse a given list (or <code>sys.argv[1:]</code> when omitted)</td><td><code>p.parse_args(["data.csv", "--n", "5"])</code></td></tr>
<tr><td><code>parse_known_args</code></td><td>Returns unknown arguments instead of failing</td><td><code>ns, rest = p.parse_known_args()</code></td></tr>
<tr><td><code>p.error(msg)</code></td><td>Print usage and exit with status 2</td><td><code>p.error("--a needs --b")</code></td></tr>
</tbody></table></div>
<h3>Example 9: arguments, defaults and types</h3>
@@py
import argparse

p = argparse.ArgumentParser(prog="clean", description="Clean a CSV file")
p.add_argument("csv", help="input file")
p.add_argument("--out", default="clean.csv", help="output file")
p.add_argument("--min-rows", type=int, default=1, help="fail if fewer rows")
p.add_argument("--dry-run", action="store_true")
p.add_argument("-v", "--verbose", action="count", default=0)

ns = p.parse_args(["orders.csv", "--min-rows", "100", "-vv"])
print(ns)
print(ns.min_rows + 1, ns.dry_run, ns.verbose)
@@end
<ol><li><code>prog</code> is the name shown in help. <code>csv</code> has no dashes so it is positional and required.</li>
<li><code>--out</code> has a default; <code>--min-rows</code> has <code>type=int</code>, so the text <code>"100"</code> becomes the integer 100. Dashes in the flag become underscores in the attribute (<code>min_rows</code>).</li>
<li><code>--dry-run</code> is a switch: absent means <code>False</code>. <code>-v</code> with <code>action="count"</code> counts how many times it appears; <code>-vv</code> gives 2.</li>
<li>We pass a list to <code>parse_args</code>, exactly what a test would do. The result is a <code>Namespace</code>, a simple object with one attribute per argument. The line <code>101 False 2</code> proves <code>min_rows</code> is a real int.</li></ol>
<h3>Example 10: errors and subcommands</h3>
@@py
import argparse
import contextlib
import io

def make_parser():
    p = argparse.ArgumentParser(prog="mlcli")
    sub = p.add_subparsers(dest="cmd", required=True)
    t = sub.add_parser("train", help="train a model")
    t.add_argument("--C", type=float, default=1.0)
    t.add_argument("--model", choices=["logreg", "tree"], default="logreg")
    t.set_defaults(func=lambda a: f"training {a.model} with C={a.C}")
    e = sub.add_parser("eval", help="evaluate a model")
    e.add_argument("run_id")
    e.set_defaults(func=lambda a: f"evaluating run {a.run_id}")
    return p

p = make_parser()
for argv in (["train", "--C", "0.5"], ["eval", "r42"]):
    a = p.parse_args(argv)
    print(a.func(a))

err = io.StringIO()
with contextlib.redirect_stderr(err):
    try:
        p.parse_args(["train", "--model", "svm"])
    except SystemExit as exc:
        print("exit status", exc.code)
print(err.getvalue().strip().splitlines()[-1])
@@end
<ol><li><code>add_subparsers</code> creates the <code>train</code> and <code>eval</code> sub-commands, each with its own flags; <code>dest="cmd"</code> stores which was chosen and <code>required=True</code> forces a choice.</li>
<li><code>set_defaults(func=...)</code> stores the function on the namespace, so the main program is just <code>args.func(args)</code>, with no long <code>if/elif</code> chain.</li>
<li>The first loop prints <code>training logreg with C=0.5</code> (default model) and <code>evaluating run r42</code>.</li>
<li>Invalid input does not raise a normal exception: argparse prints usage plus a message to stderr and calls <code>sys.exit(2)</code>. We catch <code>SystemExit</code> and capture stderr to show it: status 2, and a final line saying that <code>'svm'</code> is an invalid choice and listing the allowed ones.</li></ol>
<h3>Typer and Click (not run here)</h3>
<p><strong>Click</strong> builds commands from decorators. <strong>Typer</strong> is built on Click and uses ordinary type hints, so the function signature is the interface. Neither is installed here; the code is the standard form. Use argparse for a small script with no dependencies, Typer for a larger tool where help text, completion and tests matter.</p>
<div class="tablewrap"><table class="data"><thead><tr><th>Typer / Click item</th><th>What it does</th><th>Minimal example</th></tr></thead><tbody>
<tr><td><code>typer.Typer()</code></td><td>The application; holds commands</td><td><code>app = typer.Typer()</code></td></tr>
<tr><td><code>@app.command()</code></td><td>Registers a function as a command</td><td><code>@app.command()<br>def train(...): ...</code></td></tr>
<tr><td>parameter without default</td><td>Becomes a required argument</td><td><code>def run(csv: Path)</code></td></tr>
<tr><td>parameter with default</td><td>Becomes an option <code>--n</code></td><td><code>def run(n: int = 5)</code></td></tr>
<tr><td><code>bool</code> parameter</td><td>Becomes <code>--flag/--no-flag</code></td><td><code>dry_run: bool = False</code></td></tr>
<tr><td><code>typer.Option(...)</code>, <code>Argument(...)</code></td><td>Customise help text, names, validation</td><td><code>Annotated[int, typer.Option(min=1)]</code></td></tr>
<tr><td><code>typer.Exit(code)</code></td><td>Stop with an exit status</td><td><code>raise typer.Exit(code=1)</code></td></tr>

<tr><td><code>click.group()</code></td><td>A group of subcommands</td><td><code>@click.group()</code></td></tr>
</tbody></table></div>
@@np
# NOT RUN HERE: typer is not installed
from pathlib import Path
from typing import Annotated

import typer

app = typer.Typer(help="Tools for order files")

@app.command()
def clean(
    csv: Annotated[Path, typer.Argument(exists=True, help="input CSV")],
    out: Annotated[Path, typer.Option(help="output file")] = Path("clean.csv"),
    min_rows: Annotated[int, typer.Option(min=1)] = 1,
    dry_run: bool = False,
):
    """Remove duplicate rows."""
    typer.echo(f"cleaning {csv} -> {out} (dry_run={dry_run})")

@app.command()
def version():
    typer.echo("1.0")

if __name__ == "__main__":
    app()
@@end

<p>The Typer function reads like normal Python: <code>Path</code> makes Typer check the type, <code>exists=True</code> makes it verify the file, <code>min=1</code> rejects zero, and <code>bool</code> becomes <code>--dry-run / --no-dry-run</code>. Docstrings become help text. Test with <code>CliRunner().invoke(app, ["clean", "x.csv"])</code> and check <code>result.exit_code</code> and <code>result.stdout</code>. In a package, register the entry point in <code>pyproject.toml</code> under <code>[project.scripts]</code> (shown in section 23.4).</p>

<h3>pathlib: paths as objects</h3>
<p>Strings like <code>"data/" + name + ".csv"</code> break on Windows and when a slash is missing. <code>pathlib.Path</code> wraps a path in an object with methods; the <code>/</code> operator joins parts correctly on every operating system.</p>

<h3>Example 11: taking a path apart and building one</h3>
@@py
from pathlib import Path, PurePosixPath

p = PurePosixPath("/data/raw/orders_2026.csv.gz")
print(p.name)
print(p.stem)
print(p.suffix, p.suffixes)
print(p.parent)
print(p.with_suffix(""))
print(p.parents[1])

root = PurePosixPath("/data")
print(p.relative_to(root))
print(root / "clean" / "orders.parquet")
@@end
<ol><li><code>PurePosixPath</code> is the "paths only, never touch the disk" cousin of <code>Path</code>. We use it so the output is identical on every operating system; <code>Path</code> has the same methods.</li>
<li><code>name</code> is the final part, <code>orders_2026.csv.gz</code>. <code>stem</code> removes only the last suffix, giving <code>orders_2026.csv</code>. <code>suffix</code> is <code>.gz</code>, while <code>suffixes</code> lists <code>['.csv', '.gz']</code>.</li>
<li><code>parent</code> is <code>/data/raw</code>; <code>parents[1]</code> is two levels up, <code>/data</code>. <code>with_suffix("")</code> removes the last suffix.</li>
<li><code>relative_to(root)</code> gives <code>raw/orders_2026.csv.gz</code>. The <code>/</code> operator joins parts without any slash handling by you.</li></ol>
<h3>Example 12: files on disk, glob, and a safe write</h3>
@@py
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    (root / "raw" / "2026").mkdir(parents=True)
    (root / "raw" / "a.csv").write_text("x\n1\n")
    (root / "raw" / "2026" / "b.csv").write_text("x\n1\n2\n")
    (root / "raw" / "notes.txt").write_text("hello")

    print(sorted(p.name for p in (root / "raw").iterdir()))
    print(sorted(str(p.relative_to(root)) for p in root.rglob("*.csv")))
    print([p.stat().st_size for p in sorted(root.rglob("*.csv"))])

    # safe write: write to a temporary name, then atomically replace
    target = root / "report.json"
    tmp_file = target.with_suffix(".json.tmp")
    tmp_file.write_text('{"ok": true}')
    tmp_file.replace(target)
    print(target.read_text(), tmp_file.exists())
@@end
<ol><li><code>TemporaryDirectory</code> gives a throw-away folder removed at the end of the block. All paths are built from <code>root</code> with <code>/</code>.</li>
<li><code>mkdir(parents=True)</code> creates <code>raw</code> and <code>raw/2026</code> in one call. Without <code>parents=True</code> a missing parent raises <code>FileNotFoundError</code>.</li>
<li><code>iterdir()</code> lists direct children in arbitrary order, so we sort. The result is two files and one folder.</li>
<li><code>rglob("*.csv")</code> finds CSV files in all subfolders. The sizes are 6 and 4 bytes, because the sorted paths put <code>b.csv</code> first: <code>x\n1\n2\n</code> is six characters, <code>x\n1\n</code> is four.</li>
<li>The safe-write pattern writes a temporary file and then <code>replace</code>s the target. Readers never see a half-written file, because the rename is a single step on the same filesystem. The output ends with the JSON text and <code>False</code>: the temporary name no longer exists.</li></ol>
