16.5 Broadcasting: Combining Arrays of Different Shapes

INTUITION
Imagine painting a wall with a stencil that is only one row tall. To cover the whole wall you slide the same stencil down, row after row, without making copies of it. Broadcasting does exactly that: when one array is smaller, NumPy conceptually stretches it to fit the other, but reuses the same numbers.

Broadcasting is the set of rules that lets a + b work when the shapes differ. It is the single most useful idea in NumPy, and the source of the most puzzling errors, so learn the three rules by heart.

KEY IDEA
The three rules. Line the shapes up from the right. (1) If one shape is shorter, pad it with 1s on the left. (2) Compare axis by axis: sizes must be equal, or one of them must be 1. (3) An axis of size 1 is stretched to the other size. If any axis fails rule 2, NumPy raises ValueError: operands could not be broadcast together.

How to read it: the blue grid holds 0, 10, 20 down its rows. The orange row [0 1 2] has shape (3,), which rule 1 pads to (1, 3); rule 3 stretches the size-1 row axis to 3 (the faded copies). Each result cell is the matching blue cell plus the orange value in its column, so row 1 becomes 10 11 12.

Problem 16.5.1 Predict and check the result shapes for four combinations.

Step 1(3, 3) with (3,): pad to (1, 3), stretch to (3, 3). Fine.
Step 2(3, 1) with (1, 4): both stretch, result (3, 4). This makes an "outer" table.
Step 3(3,) with (4,): neither is 1, so it fails.
Step 4(2, 3) with (2,): aligned from the right, 3 vs 2 fails. Fix with a new axis: (2, 1).
import numpy as np A = np.array([[0, 0, 0], [10, 10, 10], [20, 20, 20]]) b = np.array([0, 1, 2]) print(A + b) col = np.array([[1], [2], [3]]) row = np.array([[10, 20, 30, 40]]) print((col * row).shape) print(col * row) try: np.ones(3) + np.ones(4) except ValueError as e: print("ValueError:", e) m = np.arange(6).reshape(2, 3) w = np.array([100, 200]) try: m + w except ValueError as e: print("ValueError:", e) print(m + w[:, None])

Line by line.

  1. col has shape (3, 1) and row has shape (1, 4). Each stretches along its size-1 axis, so the product has shape (3, 4): a multiplication table of 1..3 by 10..40.
  2. Shapes (3,) and (4,) cannot match, and NumPy says so, printing both shapes. Reading that message as "which two shapes?" is the fastest way to debug.
  3. The matrix m is (2, 3) and w is (2,). Aligned from the right, 3 meets 2 and the rule fails: the error is the classic one.
  4. w[:, None] turns w into a column of shape (2, 1). Now row 0 gets 100 added and row 1 gets 200 added.
COMMON MISTAKE
Wrong: subtract a vector of row means from a matrix with X - X.mean(axis=1). Symptom: an error, or worse, silently wrong values when the matrix happens to be square (the vector gets matched to columns instead of rows). Fix: keep the axis with X - X.mean(axis=1, keepdims=True), which makes the mean shape (n, 1).

16.6 Ufuncs, Reductions and the axis Argument

A ufunc (universal function) is a function that applies the same operation to every element, in compiled code, with broadcasting built in. +, *, np.sqrt and np.exp are all ufuncs. A reduction collapses an axis into one number, such as a sum or maximum.

The axis argument

Every reduction accepts axis. The rule that never fails: the axis you name is the one that disappears. For a table of shape (rows, columns), axis=0 collapses the rows (you get one answer per column) and axis=1 collapses the columns (one answer per row).

How to read it: in the left panel the arrows run down each column, adding 1+4, 2+5, 3+6 to get 5, 7, 9. The arrow direction is the axis that is being consumed. In the right panel the arrows run across each row, giving 6 and 15. With three or more dimensions the same rule applies: the named axis vanishes and the other axes remain.

Problem 16.6.1 A 3D array holds 2 stores, 3 days and 4 products of sales. Answer three business questions with the axis rule.

Shape(store, day, product) = (2, 3, 4).
Q1Total per store: collapse day and product, axis=(1, 2) gives shape (2,).
Q2Total per product across everything: collapse store and day, axis=(0, 1) gives (4,).
Q3Best product on each store-day: argmax(axis=2) gives (2, 3).
import numpy as np sales = np.arange(24).reshape(2, 3, 4) print(sales.sum(axis=(1, 2))) print(sales.sum(axis=(0, 1))) print(sales.argmax(axis=2)) print(sales.mean(axis=1).shape, sales.mean(axis=1, keepdims=True).shape) print(sales.cumsum(axis=1)[0]) print(np.diff(sales, axis=2)[0, 0])

Line by line.

  1. Store 0 holds 0..11 (sum 66) and store 1 holds 12..23 (sum 210). Naming a tuple of axes collapses several at once.
  2. Summing store and day leaves one total per product: the four sums are 60, 66, 72, 78.
  3. Without keepdims the day axis vanishes: (2, 4). With it, a length-1 axis stays: (2, 1, 4). Keeping it lets the result broadcast back against the original.
  4. cumsum(axis=1) accumulates across days within each store; we print store 0, whose last row is the 3-day running total.
COMMON MISTAKE
Wrong: np.mean(x) on a 2D array when you wanted per-column means, or np.std(x) to estimate a sample's spread. Symptom: a single number instead of a vector; and a standard deviation that is slightly too small. Fix: pass axis=0, and use ddof=1 for the sample standard deviation (NumPy defaults to ddof=0, the population version; pandas defaults to 1).

Problem 16.7.1 Combine and cut arrays: concatenate vs stack, then split a dataset into folds.

Ideaconcatenate glues along an existing axis; stack adds a new one. array_split tolerates sizes that do not divide evenly.
import numpy as np a = np.array([[1, 2], [3, 4]]) b = np.array([[5, 6], [7, 8]]) print(np.concatenate([a, b], axis=0).shape) print(np.concatenate([a, b], axis=1).shape) print(np.stack([a, b]).shape, np.stack([a, b], axis=2).shape) print(np.vstack([a, b]).shape, np.hstack([a, b]).shape) x = np.array([1, 2, 3]) y = np.array([10, 20, 30]) print(np.column_stack([x, y])) parts = np.array_split(np.arange(10), 3) print([p.tolist() for p in parts]) print(np.roll(np.arange(5), 2), np.pad(a, 1).shape)

Line by line.

  1. stack creates a new axis: at the front it gives (2, 2, 2) as "two matrices"; with axis=2 the new axis is last.
  2. column_stack places each 1D array as a column: rows are [1 10], [2 20], [3 30].
  3. Ten items into three folds cannot be equal, so array_split gives sizes 4, 3, 3 (the first folds get the extra item).
  4. np.roll(..., 2) shifts right by two, wrapping the end around to the front. pad(a, 1) adds a one-cell border: (2, 2) becomes (4, 4).
