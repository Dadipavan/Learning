20.3 Text formats: csv, json and yaml

These three formats cover most files you will meet. CSV is a flat table in text, JSON is nested data (dicts and lists), and YAML is human-friendly nested data, mostly used for configuration. The golden rule: parse them with a real parser, never with line.split(","), because real data contains commas and quotes inside values.

Example 1: write and read CSV with quotes inside values

import csv, io

buf = io.StringIO()
w = csv.DictWriter(buf, fieldnames=["id", "name", "amount"], lineterminator="\n")
w.writeheader()
w.writerow({"id": 1, "name": "Ana, Jr.", "amount": 12.5})
w.writerow({"id": 2, "name": 'Bo "B" Lee', "amount": 7})
text = buf.getvalue()
print(text)

rows = list(csv.DictReader(io.StringIO(text)))
print(rows[0])
print(type(rows[0]["amount"]).__name__)
print(sum(float(r["amount"]) for r in rows))
@@
  1. io.StringIO is an in-memory "file", handy for demos; with a real file you would use open(path, "w", newline="", encoding="utf-8").
  2. DictWriter needs the column names. lineterminator="\n" avoids the default \r\n, so the output is the same on every system.
  3. The two rows contain a comma and double quotes. The writer wraps the first name in quotes and doubles the inner quotes (""), which is the CSV rule for a quote inside a quoted value.
  4. DictReader reads it back correctly: the comma stayed inside the name.
  5. Every value comes back as a string, including amount. CSV has no types, so you convert with float() yourself (or let pandas guess).
  6. The last line adds 12.5 and 7.0 to get 19.5.

Example 2: nested JSON Lines, the JSON date trap and a YAML config

import json, yaml
from datetime import date
import pandas as pd

print(json.dumps({"when": date(2025, 3, 1), "note": "café"}, default=str, ensure_ascii=False))
try:
    json.loads("{'a': 1}")
except json.JSONDecodeError as e:
    print("bad json:", e.msg, "at char", e.pos)

lines = (
    '{"id": 1, "user": {"name": "Ana", "tier": "gold"}, "total": 30}\n'
    '{"id": 2, "user": {"name": "Bo", "tier": "basic"}, "total": 12}\n'
)
records = [json.loads(line) for line in lines.splitlines()]
df = pd.json_normalize(records)
print(df)

cfg = yaml.safe_load("""
source:
  path: data/orders.jsonl
  encoding: utf-8
columns: [id, total]
dropna: true
""")
print(cfg)
print(df[cfg["columns"]].sum().to_dict())
print(yaml.safe_dump({"a": [1, 2], "b": {"c": None}}, sort_keys=False))
@@
  1. JSON cannot hold a date, so dumps would raise TypeError; default=str converts unknown objects (reading it back gives a string, so convert dates yourself). ensure_ascii=False keeps the accent. The bad-JSON test uses single quotes, which JSON forbids; the exception carries msg and pos, which is what you log.
  2. The string is JSON Lines: one JSON object per line, so a huge file can be processed line by line.
  3. Each line is parsed on its own; json_normalize flattens the inner user dict into columns user.name and user.tier.
  4. yaml.safe_load parses the triple-quoted text. Indentation means nesting; [id, total] is a list; true becomes Python True.
  5. The config drives the code: the column list picks two columns and sums them.
  6. safe_dump writes YAML back. sort_keys=False keeps your order and None becomes null.
COMMON MISTAKE
Wrong: yaml.load(text). Symptom: in old PyYAML it could construct arbitrary Python objects from a malicious file, which is a code-execution risk; in PyYAML 6 it fails with a missing Loader argument. Fix: always call yaml.safe_load for data you did not write yourself.

20.4 Excel: openpyxl and pandas

Excel files are everywhere in business: budgets, exports, hand-edited lists. An .xlsx file is a zip of XML files. openpyxl reads and writes it cell by cell, with formatting and formulas. pandas.read_excel and DataFrame.to_excel use openpyxl underneath for the whole-table case.

Example 1: create, save, reload, and the formula trap

import tempfile
from pathlib import Path
from openpyxl import Workbook, load_workbook

path = Path(tempfile.mkdtemp()) / "sales.xlsx"
wb = Workbook()
ws = wb.active
ws.title = "Sales"
ws.append(["region", "units"])
for row in [("north", 120), ("south", 95), ("east", 143)]:
    ws.append(row)
ws["B5"] = "=SUM(B2:B4)"
wb.save(path)

sheet = load_workbook(path)["Sales"]
print(sheet.max_row, sheet.max_column)
for region, units in sheet.iter_rows(min_row=2, max_row=4, values_only=True):
    print(region, units)
print(sheet["B5"].value, load_workbook(path, data_only=True)["Sales"]["B5"].value)
@@
  1. A new Workbook has one sheet; append adds a row per call. Nothing exists on disk until wb.save.
  2. After reloading, max_row is 5 (header, three rows and the formula row) and max_column is 2. iter_rows(values_only=True) yields plain tuples; without it you get cell objects.
  3. Cell B5 stores the text of a formula. A normal load returns that text. With data_only=True you ask for the cached result, but only Excel writes that cache; openpyxl never calculates, so you get None.
  4. Lesson: formulas written by a script have no values until a spreadsheet application saves the file. Compute in pandas and write values instead.

Example 2: a multi-sheet report with pandas

import tempfile
from pathlib import Path
import pandas as pd

path = Path(tempfile.mkdtemp()) / "report.xlsx"
sales = pd.DataFrame({"region": ["north", "south", "east"], "units": [120, 95, 143]})
notes = pd.DataFrame({"note": ["Prepared by Priya"]})
with pd.ExcelWriter(path, engine="openpyxl") as writer:
    sales.to_excel(writer, sheet_name="Sales", index=False)
    notes.to_excel(writer, sheet_name="Notes", index=False)

everything = pd.read_excel(path, sheet_name=None)
print(list(everything))
print(everything["Sales"])
print(pd.read_excel(path, sheet_name="Sales", usecols="B").columns.tolist())
print(pd.read_excel(path, sheet_name="Sales", dtype={"units": "float64"})["units"].dtype)
@@
  1. ExcelWriter as a context manager saves and closes the file when the with block ends.
  2. Each to_excel call writes one sheet; index=False avoids an unwanted extra column holding 0, 1, 2.
  3. sheet_name=None reads every sheet into a dict of DataFrames, keyed by sheet name.
  4. usecols="B" uses Excel column letters and returns only the second column.
  5. dtype forces a type on read, here turning whole numbers into floats. Use it to keep codes as text, for example dtype={"zip": str}.
