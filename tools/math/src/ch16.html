16.1 How Interviews Test Math

BASIC EXPLANATION
Math interviews test whether you can explain and apply core ideas such as linear algebra, calculus, probability and optimisation. This section describes the types of question asked and how to structure a clear answer.
INTUITION
An interviewer cannot see how much you know. They sample. Each question is a small probe: can this person state an idea precisely, apply it to numbers, notice when it fails, and stay calm while doing so? You are scored on the sample, so a clear, correct, short answer to ten probes beats a rambling brilliant answer to two.

Beginner: the six question formats

  • Concept: "What does the determinant mean?" You need one sentence, one example and one limit.
  • Calculation: "What is the cross-entropy between these two distributions?" Small numbers, done aloud.
  • Derivation: "Derive the gradient of logistic regression." You write every line and name each rule you use.
  • Estimation: "How much memory do a million 768-dimensional embeddings need?" Powers of ten and clean arithmetic.
  • Debugging: "This code computes variance. What is wrong?" Spot n versus n-1, a missing transpose or a shape bug.
  • Scenario: "Training loss is NaN after 50 steps. What do you check?" Math as a diagnostic tool (overflow, log of zero, learning rate).

The four-step answer

The Statistics document (Chapter 14) introduced a method for explaining a concept. It works for math too. 1. Say it in one plain sentence. 2. Give a tiny example with numbers. 3. Say why it matters for a decision or a model. 4. State the limit or the common misreading. Every model answer in the banks below follows this shape, compressed into the Answer row. The Follow-up row is what a good interviewer asks next. The Trap row is the error that costs you the point.

COMMON MISTAKE
Reciting a formula without saying what it means. Wrong: "The determinant is ad − bc." Right: "The determinant is the factor by which a matrix scales area (volume in higher dimensions), with sign for a flip; for a 2×2 matrix it equals ad − bc, and zero means the matrix squashes space onto a line, so it has no inverse." The first answer proves you memorised, the second proves you understand.

Going deeper: how interviewers score

Most rubrics have four lines: correctness, clarity, depth under follow-up and handling of mistakes. The last one surprises people. If you make an arithmetic slip, say "let me recheck that step" and fix it. Interviewers rate a visible self-check above a flawless run, because on the job nobody is flawless and the useful people catch errors. Use units and shapes as free checks: in a gradient, the shape of the gradient must equal the shape of the parameter. In a probability, the answer must lie in [0, 1]. In an estimate, compare with something you know.

16.2 Algebra, Logs and Growth

These questions look easy and are the ones most often failed under pressure, because they involve quick mental arithmetic. See Chapters 1 to 4 for the full theory.

Q16.2.1 Solve 2x = 10.

AnswerTake logs: x = log210 = ln 10 / ln 2 = 2.3026 / 0.6931 = 3.3219. Check: 23 = 8 and 24 = 16, so x lies between 3 and 4.
Follow-upEstimate it without a calculator. Since 210 = 1024 ≈ 103, we have 210/3 ≈ 10, so log210 ≈ 10/3 = 3.33.
TrapWriting log(a + b) = log a + log b. Logs turn products into sums, never sums into sums.

Q16.2.2 Why do we maximise the log-likelihood instead of the likelihood?

AnswerThe log is strictly increasing, so it has the same maximiser. It turns a product of n probabilities into a sum, which is easier to differentiate and does not underflow.
Follow-upGive a number. A product of 1000 probabilities each 0.01 is 10−2000, below the smallest float64 (about 10−308), so it becomes 0.0. The log-sum is 1000 × ln 0.01 = −4605.17, perfectly fine.
TrapForgetting that minimising the negative log-likelihood is the same problem. Also, the log likelihood value changes with the log base but the argmax does not.

Q16.2.3 State the rule of 72 and say when it is accurate.

AnswerDoubling time ≈ 72 / r years for r percent growth per year. At 8% it gives 9 years. Exact: ln 2 / ln 1.08 = 0.6931 / 0.07696 = 9.006 years.
Follow-upWhy 72 and not 69? ln 2 = 0.693, and ln(1+r) ≈ r for small r gives 69.3 / r. 72 is used because it divides by 2, 3, 4, 6, 8, 9, 12 and corrects for the fact that ln(1+r) < r.
TrapUsing it at extreme rates. At 100% growth it says 0.72 years but the true doubling time is exactly 1.

Q16.2.4 Revenue grows 5% every month. By what percent does it grow in a year?

AnswerGrowth factors multiply: 1.0512 = 1.7959, so about 79.6%, not 60%.
Follow-upWhat constant monthly rate gives exactly 100% a year? 21/12 = 1.0595, so about 5.95% a month.
TrapAdding percentages (12 × 5% = 60%). Compounding always beats simple addition for positive rates.

Q16.2.5 A metric rises 50% and then falls 50%. Where does it end up? Which drop undoes a 25% loss?

Answer1.5 × 0.5 = 0.75, a net 25% loss. To undo a 25% loss you need a factor of 1/0.75 = 1.3333, a 33.3% gain.
Follow-upWhich average describes a series of growth factors? The geometric mean: (1.5 × 0.5)1/2 = 0.866 per period, a 13.4% loss per period.
TrapAveraging 50% and −50% to get 0%. Percentages are relative to a changing base.

Q16.2.6 Compare 2n and n3. Which is bigger and when does the winner take over for good?

AnswerFor n = 9: 512 < 729. For n = 10: 1024 > 1000. From n = 10 onward, 2n wins for good because each step multiplies 2n by 2 while n3 grows by the factor (1 + 1/n)3 ≤ 1.33 (at n = 10), which is below 2.
Follow-upWhat about 2n versus n100? Still exponential wins eventually, only much later. Exponentials beat every polynomial.
TrapDeclaring a winner from one value of n. At n = 1, 2n = 2 beats n3 = 1, yet n3 wins for every n from 2 to 9. Only from n = 10 on does 2n stay ahead.

Q16.2.7 Derive 1 + 2 + ... + n and use it for n = 100. Also give the sum of squares.

AnswerWrite the sum forwards and backwards and add: n pairs each equal to n + 1, so 2S = n(n + 1) and S = n(n + 1)/2. For n = 100: 100 × 101 / 2 = 5050. Sum of squares: n(n + 1)(2n + 1)/6, for n = 10 equals 10 × 11 × 21 / 6 = 385.
Follow-upWhere does it appear? Loop cost: a double loop over pairs i < j does n(n − 1)/2 steps, which is O(n²).
TrapOff-by-one: the sum 0 + 1 + ... + (n − 1) is n(n − 1)/2, not n(n + 1)/2.

Q16.2.8 Sum the geometric series 1 + r + r2 + ... What is the discounted value of reward 1 every step with γ = 0.9?

AnswerFinite: (1 − rn)/(1 − r). Infinite, valid for |r| < 1: 1/(1 − r). With γ = 0.9 the total is 1/(1 − 0.9) = 10.
Follow-upProve it: S − rS = 1 − rn, so S = (1 − rn)/(1 − r). This is the discounted return in reinforcement learning.
TrapUsing the infinite formula when |r| ≥ 1. At r = 1 the finite sum is simply n.

Q16.2.9 How many bits are needed to label 1,000,000 distinct items?

Answerceil(log2 1,000,000) = ceil(19.93) = 20 bits. Check: 219 = 524,288 is too small, 220 = 1,048,576 is enough.
Follow-upHow many binary-search steps to find one item among 109? ceil(log2 109) = ceil(29.9) = 30.
TrapRounding down. You need the ceiling, because 19 bits can only label 524,288 items.

Q16.2.10 A learning rate halves every 10 epochs. What is it after 25 epochs?

Answerlr = lr0 × 0.5t/10 = lr0 × 0.52.5 = 0.1768 lr0.
Follow-upHow would you write it as e−kt? k = ln 2 / 10 = 0.0693 per epoch.
TrapConfusing half-life with decay rate. The half-life T and the rate k are linked by k = ln 2 / T.

Q16.2.11 How many digits does 2100 have?

AnswerDigits = floor(100 log102) + 1 = floor(30.103) + 1 = 31. Indeed 2100 = 1.2676 × 1030.
Follow-upSame trick for the number of digits of n! with Stirling's formula, or of any large power.
TrapForgetting the +1. A number with value 10k has k + 1 digits, so digits = floor(log10 x) + 1.

Q16.2.12 Why plot a growing quantity on a log axis? What does the slope mean?

AnswerConstant percentage growth r per step gives y = y0(1 + r)t, and log y = log y0 + t log(1 + r) is a straight line with slope log(1 + r). A curve that bends up on a linear axis becomes a line; a bend on the log axis means the growth rate itself is changing.
Follow-upA series contains zeros. What do you do? Use log(1 + y), implemented by log1p, which also keeps accuracy for tiny y.
TrapReading the log-axis slope as an absolute increase. It is a relative growth rate.

16.3 Linear Algebra

The core of ML interviews. Chapters 5 to 9 hold the full story. Each answer below fits in under a minute.

Q16.3.1 What is the rank of a matrix?

AnswerThe number of linearly independent columns, which equals the number of linearly independent rows, which equals the dimension of the column space. Example: [[1, 2], [2, 4]] has rank 1 because row 2 is twice row 1.
Follow-upWhat is the largest possible rank of a 100×5 matrix? 5. And rank(AB) ≤ min(rank A, rank B).
TrapCounting nonzero entries or nonzero rows of the raw matrix. In floating point, rank is the number of singular values above a tolerance.

Q16.3.2 What is an eigenvector? Find the eigenvalues of [[2, 1], [1, 2]].

AnswerA nonzero v with Av = λv: the matrix only stretches it. Solve det(A − λI) = (2 − λ)² − 1 = 0, giving λ = 3 and λ = 1, with eigenvectors (1, 1) and (1, −1).
Follow-upWhy are those two orthogonal? The matrix is symmetric, and eigenvectors of a symmetric matrix for different eigenvalues are orthogonal.
TrapSaying eigenvectors are unique. Any nonzero multiple works. Also, a real matrix may have complex eigenvalues (a 90° rotation has ±i).

Q16.3.3 How do the trace and determinant relate to eigenvalues?

AnswerTrace = sum of eigenvalues, determinant = product of eigenvalues (counted with multiplicity). For [[2, 1], [1, 2]]: trace 4 = 3 + 1, det 3 = 3 × 1.
Follow-upWhat does a zero eigenvalue imply? The determinant is zero, the matrix is singular, and its null space is nonzero.
TrapThinking this holds only for symmetric matrices. It holds for every square matrix, over the complex numbers.

Q16.3.4 What does the determinant mean geometrically?

AnswerThe signed factor by which the linear map scales area (2D) or volume (3D). diag(2, 3) scales area by 6. A negative sign means orientation is flipped (a reflection).
Follow-upWhat are det(AB) and det(cA) for an n×n matrix? det(A)det(B) and cn det(A).
TrapBelieving det(A + B) = det A + det B. It does not.

Q16.3.5 Why do practitioners avoid computing A−1 to solve Ax = b?

AnswerFactorising (LU, Cholesky or QR) and then solving by substitution is faster and more accurate than forming the inverse and multiplying. An explicit inverse also destroys sparsity and amplifies rounding error when A is ill-conditioned.
Follow-upHow do you solve least squares? Use QR or SVD (np.linalg.lstsq), not (XTX)−1XTy, because forming XTX squares the condition number.
TrapSaying you can never use an inverse. The diagonal of (XTX)−1 gives coefficient variances in regression, so sometimes you really need it, for small matrices.

Q16.3.6 What is the difference between eigendecomposition and SVD?

AnswerEigendecomposition A = QΛQ−1 needs a square, diagonalizable matrix. SVD A = UΣVT exists for every m×n matrix, with orthogonal U, V and non-negative singular values σi = sqrt(eigenvalues of ATA).
Follow-upWhen do they coincide? For a symmetric positive semi-definite matrix: singular values equal eigenvalues and U = V.
TrapEquating singular values with eigenvalues for any matrix. For a symmetric matrix, σ = |λ|; for a non-symmetric one, they differ in general.

Q16.3.7 How does PCA relate to SVD?

AnswerCentre the data matrix X (n×p). Compute X = UΣVT. The columns of V are the principal axes, the variance along axis i is σi² / (n − 1) and the scores are XV = UΣ.
Follow-upWhy use SVD rather than eigendecomposition of the covariance? It avoids forming XTX, which squares the condition number, and it handles p > n gracefully.
TrapForgetting to centre. Without centring, the first component mostly points at the mean.

Q16.3.8 Define cosine similarity and compute it for (1, 2, 3) and (2, 4, 6) and for (1, 0) and (0, 1).

Answercos θ = a·b / (‖a‖‖b‖). First pair: 28 / (√14 × √56) = 28 / 28 = 1 (same direction). Second pair: 0 / 1 = 0 (orthogonal).
Follow-upHow does it relate to Euclidean distance for unit vectors? ‖a − b‖² = 2 − 2 cos θ.
TrapCalling 1 − cos a metric (the triangle inequality can fail) and ignoring that cosine ignores magnitude.

Q16.3.9 What is correlation in terms of cosine similarity?

AnswerPearson correlation is the cosine similarity of the two centred vectors. Centre each vector by its mean, then take the cosine.
Follow-upExample: a = (1, 2, 3), b = (1, 1, 2). Raw cosine = 9/(√14 √6) = 0.982. Centred: (−1, 0, 1) and (−0.333, −0.333, 0.667), cosine = 1 / (√2 × 0.8165) = 0.866.
TrapTreating the raw cosine as correlation. They agree only when both vectors have mean zero.

Q16.3.10 What is a positive definite matrix? How do you check it?

AnswerA symmetric matrix A with xTAx > 0 for all x ≠ 0. Equivalent tests: all eigenvalues positive, all leading principal minors positive, or a Cholesky factorisation exists. [[2, 1], [1, 2]] has eigenvalues 3, 1: positive definite. [[1, 2], [2, 1]] has eigenvalues 3, −1: indefinite.
Follow-upIs XTX positive definite? It is always positive semi-definite (xTXTXx = ‖Xx‖² ≥ 0) and positive definite exactly when X has full column rank.
TrapBelieving a matrix with all positive entries is positive definite. [[1, 2], [2, 1]] is a counterexample.

Q16.3.11 What is an orthogonal matrix and why is it nice?

AnswerQTQ = I, so Q−1 = QT. It preserves lengths and angles (‖Qx‖ = ‖x‖) and has det ±1. Rotations and reflections are orthogonal.
Follow-upWhy do ML people like orthogonal initialisation? Repeated multiplication by Q neither shrinks nor blows up a signal, since all singular values equal 1.
TrapConfusing orthogonal (orthonormal columns, square) with merely orthogonal columns of different lengths.

Q16.3.12 A 1000×1000 matrix pair A, B and a vector x. Compare costs of (AB)x and A(Bx).

Answer(AB)x: the matrix product costs about 1000³ = 109 multiply-adds plus 106. A(Bx): two matrix-vector products, 2 × 106. Same result by associativity, 500 times cheaper.
Follow-upShape rule: (m×k)(k×n) costs m·k·n multiply-adds. Where does this matter? Attention and low-rank updates such as LoRA.
TrapAssuming order is irrelevant for cost. Associativity holds exactly, but cost depends on the bracketing. Commutativity does not hold: AB ≠ BA.

Q16.3.13 What is the condition number and what does it tell you?

Answerκ = σmax / σmin. Relative errors in b can be amplified by up to κ in the solution of Ax = b, so you lose roughly log10κ digits of accuracy. diag(1, 10−6) has κ = 106.
Follow-upIs a tiny determinant a sign of ill-conditioning? Not necessarily: 10−10 I (2×2) has det 10−20 but κ = 1.
TrapUsing the determinant as a singularity measure. Use κ or the smallest singular value.

Q16.3.14 Why does ridge regression always have a solution?

AnswerThe matrix XTX + λI has eigenvalues σi² + λ ≥ λ > 0, so it is positive definite and invertible, even when columns of X are collinear or p > n.
Follow-upWhat happens to the coefficients along small-singular-value directions? They are shrunk by the factor σ² / (σ² + λ), which is near 0 when σ is small.
TrapThinking ridge makes coefficients exactly zero. It shrinks, never zeroes (that is L1).

Treating the determinant as additive or the eigenvalues of A + B as the sums of eigenvalues. Wrong: det(A + B) = det A + det B, or λ(A + B) = λ(A) + λ(B). Right: det(AB) = det A × det B, and eigenvalues add only when A and B share eigenvectors. Test with A = diag(1, 0) and B = diag(0, 1): det A = det B = 0 but det(A + B) = det I = 1.

16.4 Calculus and Backpropagation

Interviewers love to say "derive it". Chapters 10 to 13 give the tools; the habit to build is naming each rule as you apply it.

Q16.4.1 Derive the derivative of the sigmoid σ(x) = 1/(1 + e−x).

AnswerWrite σ = (1 + e−x)−1. Chain rule: σ' = −(1 + e−x)−2 × (−e−x) = e−x / (1 + e−x)². Split it as [1/(1 + e−x)] × [e−x/(1 + e−x)] = σ(1 − σ). At x = 0, σ = 0.5 and σ' = 0.25, the maximum.
Follow-upWhat does the maximum of 0.25 imply for deep sigmoid networks? Gradients shrink by at least a factor 4 per layer from the activation alone.
TrapDropping the minus signs: two negatives (from the power and from the inner derivative) cancel, leaving a positive derivative.

Q16.4.2 What are the derivatives of tanh and ReLU?

Answertanh' = 1 − tanh²(x), maximum 1 at 0. ReLU(x) = max(0, x) has derivative 1 for x > 0 and 0 for x < 0; at exactly 0 it is undefined and frameworks pick 0.
Follow-upWhy is tanh better than sigmoid inside a network? It is zero-centred and its slope reaches 1, not 0.25.
TrapSaying ReLU "has no gradient". It has gradient 1 on the active side, which is exactly why it avoids shrinking.

Q16.4.3 Write the gradient of the mean squared error for linear regression.

AnswerL = (1/n)‖Xw − y‖². Then ∇wL = (2/n) XT(Xw − y). Shapes: XT is p×n, the residual is n×1, so the gradient is p×1, matching w.
Follow-upWhat changes if the loss is (1/2n)‖Xw − y‖²? The 2 cancels: (1/n) XT(Xw − y).
TrapLosing the factor 2 or the 1/n. A shape check catches transposes; a finite-difference check catches constants.

Q16.4.4 Derive the gradient of binary cross-entropy for p = σ(z), z = w·x + b.

AnswerL = −[y ln p + (1 − y) ln(1 − p)]. dL/dp = −y/p + (1 − y)/(1 − p). dp/dz = p(1 − p). Multiply: dL/dz = −y(1 − p) + (1 − y)p = p − y. So ∇wL = (p − y) x and ∂L/∂b = p − y.
Follow-upWhy is that so neat? The p(1 − p) from the sigmoid cancels the denominators of the log, so the gradient does not vanish when the model is confidently wrong.
TrapApplying MSE with a sigmoid instead. Then the gradient has an extra p(1 − p) factor and learning stalls when the output is saturated and wrong.

Q16.4.5 Explain vanishing gradients.

AnswerBackprop multiplies one local derivative per layer. If those factors are below 1 in size (sigmoid ≤ 0.25), the product shrinks exponentially: ten sigmoid layers give at most 0.2510 ≈ 9.5 × 10−7. Early layers then barely learn.
Follow-upHow do you fix it? ReLU-type activations, residual connections (the identity path gives a factor 1), normalisation layers, careful initialisation and gradient clipping for the opposite problem, exploding gradients.
TrapBlaming only the activation. Weight matrices matter too: the factor per layer is (weights) × (activation slope), so both can cause shrinkage or explosion.

Q16.4.6 Chain rule on a small graph: z = wx + b with x = 2, w = 3, b = 1, target y = 5 and L = (z − y)². Find dL/dw, dL/db, dL/dx.

AnswerForward: z = 7, r = z − y = 2, L = 4. Backward: dL/dr = 2r = 4, so dL/dz = 4. Then dL/dw = 4 × x = 8, dL/db = 4 × 1 = 4, dL/dx = 4 × w = 12.
Follow-upWhat if x feeds into two nodes? Add the contributions of every path (the multivariable chain rule).
TrapForgetting to sum over multiple uses of a variable, a classic backprop bug for weight sharing.

Q16.4.7 Derive the gradient of softmax cross-entropy with respect to the logits.

Answerpi = ezi / Σk ezk, L = −Σ yi ln pi. Result: ∂L/∂zj = pj − yj. Full derivation in 16.9.
Follow-upExample: z = (2, 1, 0), true class is the first one: p = (0.665, 0.245, 0.090), gradient = (−0.335, 0.245, 0.090). It sums to 0.
TrapDifferentiating softmax and the loss separately and getting lost in the Jacobian. Combine them first: the log cancels the exponential.

Q16.4.8 Which direction does the gradient point and why does gradient descent use its negative?

AnswerThe gradient points in the direction of steepest increase, and it is perpendicular to level curves. The directional derivative along a unit vector u is ∇f·u = ‖∇f‖ cos θ, maximal at θ = 0. To decrease f, move along −∇f.
Follow-upWhat is the size of the first-order decrease for a small step η? About η‖∇f‖².
TrapCalling the gradient "the slope". It is a vector of partial derivatives, not a scalar.

Q16.4.9 Give the shapes of the gradient, Jacobian and Hessian.

AnswerFor f: Rn → R, the gradient is n×1 and the Hessian is n×n (symmetric when f is smooth). For f: Rn → Rm, the Jacobian is m×n.
Follow-upWhat does a positive semi-definite Hessian tell you? Locally convex: a stationary point there is a minimum.
TrapMixing up m×n and n×m. The Jacobian of a linear map x → Ax is A itself, an m×n matrix.

Q16.4.10 Use a second-order Taylor expansion to derive Newton's method and take one step on f(x) = ex − 2x from x = 0.

Answerf(x + h) ≈ f + f'h + ½f''h². Setting the derivative in h to zero: h = −f'/f''. Here f' = ex − 2 = −1 and f'' = 1 at 0, so h = 1 and x becomes 1. The true minimiser is ln 2 = 0.693; the next step from 1 gives 0.736.
Follow-upWhat goes wrong if f'' < 0? The step goes toward a maximum. Newton finds stationary points, not necessarily minima.
TrapUsing Newton in high dimensions without noting the cost: the Hessian has p² entries and inverting it costs p³.

Q16.4.11 Why is backpropagation (reverse mode) used instead of forward mode?

AnswerFor a scalar loss and p parameters, reverse mode gives all p partial derivatives in one backward sweep costing about 2 to 3 forward passes. Forward mode needs one pass per parameter, p passes in total.
Follow-upWhen is forward mode better? When there are few inputs and many outputs.
TrapThinking backprop is a different algorithm from the chain rule. It is the chain rule evaluated in the efficient order, with cached forward activations.

Q16.4.12 What is the derivative of log-sum-exp, and how do you compute it stably?

Answer∂/∂zj ln Σ ezk = softmax(z)j. Stable form: m + ln Σ ezk − m with m = max z.
Follow-upWhy does it work? Subtracting m leaves all exponents ≤ 0, so no overflow, and the largest term is exactly 1 so no total underflow.
TrapComputing ln(sum(exp(z))) directly: exp(1000) is infinity in float64.

Q16.4.13 The L1 penalty |w| is not differentiable at 0. What do optimisers do?

AnswerThey use a subgradient: sign(w) for w ≠ 0 and any value in [−1, 1] at 0. Proximal methods apply soft-thresholding: w ← sign(w) max(|w| − ηλ, 0), which sets small weights exactly to zero.
Follow-upDoes autograd do this? It returns 0 at 0 for |w|, which with plain SGD never lands exactly on zero.
TrapSaying L1 is "not allowed" because it is not smooth. Convex and non-smooth is fine; ReLU networks are non-smooth too.

16.5 Optimization

Chapter 14 covers the theory. These questions test whether you can explain behaviour and not just name algorithms.

Q16.5.1 Why is Adam so popular? State the update.

AnswerIt combines momentum (a running mean of gradients m) with per-parameter step scaling (a running mean of squared gradients v): m ← β1m + (1 − β1)g, v ← β2v + (1 − β2)g², then θ ← θ − η m̂/(√v̂ + ε), where m̂ and v̂ are bias-corrected. Defaults: β1 = 0.9, β2 = 0.999, ε = 10−8. Parameters with small, consistent gradients get relatively larger steps.
Follow-upHow large is the very first step? m̂ = g and v̂ = g², so the step is η g/(|g| + ε) ≈ η sign(g): size η per coordinate regardless of gradient scale.
TrapClaiming Adam always generalises better. Plain SGD with momentum often wins on image tasks. Also, L2 regularisation inside Adam differs from decoupled weight decay (AdamW).

Q16.5.2 Why does a too-large learning rate fail? How big is too big?

AnswerOn f = ½ a x², gradient descent gives x ← (1 − ηa)x. It converges only if |1 − ηa| < 1, i.e. 0 < η < 2/a. For a = 10, η = 0.21 gives a factor −1.1: the iterates flip sign and grow. η = 1/a = 0.1 lands on the minimum in one step.
Follow-upFor a general smooth loss? The same idea with a replaced by the largest Hessian eigenvalue L: guaranteed descent for η ≤ 1/L, instability beyond 2/L.
TrapRemembering the threshold as 1/L. That is the safe step; divergence begins at 2/L.

Q16.5.3 Convex versus non-convex: define and give examples.

Answerf is convex if f(λx + (1 − λ)y) ≤ λf(x) + (1 − λ)f(y) for λ in [0, 1]: chords lie above the graph. For smooth f, the Hessian is positive semi-definite everywhere. Every local minimum is global. Linear and logistic regression losses are convex, neural-network losses are not.
Follow-upShow a simple non-convexity in a neural-network-like loss: f(a, b) = (ab − 1)². f(1, 1) = f(−1, −1) = 0 but the midpoint f(0, 0) = 1 > 0, violating convexity.
TrapSaying convex implies a unique minimiser. A flat bottom gives many minimisers; strict convexity gives uniqueness.

Q16.5.4 Explain L1 versus L2 regularisation geometrically.

AnswerConstrained view: minimise the loss inside ‖w‖1 ≤ t (a diamond with corners on the axes) or ‖w‖2 ≤ t (a circle). The loss contours usually first touch the diamond at a corner, where some coordinates are exactly zero. A circle has no corners, so every weight stays nonzero.
Follow-upPenalty view: L1 pulls with constant force λ sign(w), reaching zero in finite time. L2 pulls with force 2λw, which fades as w shrinks. Shrinking a = 0.8 and a = 0.2 with λ = 0.25: L1 soft-threshold gives 0.55 and 0; ridge a/(1 + 2λ) gives 0.533 and 0.133.
TrapPromising that L1 always finds the true sparse set. With correlated features it picks one arbitrarily among them.

Q16.5.5 Why does SGD's noise help, and why is it a problem?

AnswerA minibatch gradient is an unbiased estimate of the full gradient with variance proportional to 1/B. The noise lets the iterate bounce out of sharp minima and saddle points and often lands in flatter minima that generalise well. It is also why SGD with constant learning rate never settles, so you decay the rate.
Follow-upHow does batch size change it? Going from B = 1 to B = 64 reduces the gradient's standard deviation by √64 = 8.
TrapThinking bigger batches are always better. They cut noise, but also cost more per step and can hurt generalisation unless you scale the learning rate.

Q16.5.6 What does momentum do?

Answerv ← βv + g, θ ← θ − ηv. In a steady direction the steps add up to an effective rate η/(1 − β): ten times larger for β = 0.9. In a zig-zag direction (a narrow valley), alternating gradients cancel.
Follow-upWhy does it help a ravine? The valley floor's gradient components add, the steep walls' components cancel.
TrapForgetting the effective-rate effect. Switching to momentum without lowering η can destabilise training.

Q16.5.7 Saddle points versus local minima: which matters more in deep learning?

AnswerAt a saddle the Hessian has both positive and negative eigenvalues, like f = x² − y² at the origin (Hessian diag(2, −2)). In high dimension a random critical point is far more likely to have some negative directions, so saddles are more common than bad local minima. Noise and momentum help leave them.
Follow-upHow do you tell them apart? The Hessian eigenvalue signs: all positive means minimum, mixed means saddle.
TrapStating this as a theorem for every network. It is a well-supported heuristic, not a guarantee.

Q16.5.8 Compare Newton's method with gradient descent.

AnswerNewton: θ ← θ − H−1g. It uses curvature, converges quadratically near a minimum and solves a quadratic in one step. Each step costs O(p³), and H must be positive definite. Gradient descent costs O(p) per step but needs many steps.
Follow-upWhat is the compromise? Quasi-Newton methods (BFGS, L-BFGS) build a curvature estimate from gradients.
TrapUsing Newton on a non-convex loss without checking H: it may head to a maximum.

Q16.5.9 Normal equation versus gradient descent for linear regression: when to use which?

AnswerNormal equation XTXw = XTy costs O(np² + p³) and is exact; gradient descent costs O(np) per step. For p up to a few thousand, a stable solver is fine; for huge p or n, use (stochastic) gradient methods.
Follow-upIs solving the normal equation by inverting XTX wise? No, use QR or SVD, as in 16.3.
TrapChoosing GD only because it "sounds more machine-learning".

Q16.5.10 Why does feature scaling speed up gradient descent?

AnswerOn a quadratic with Hessian eigenvalues λmax and λmin, the best fixed step is 2/(λmax + λmin) and the error shrinks by (κ − 1)/(κ + 1) per step, where κ = λmax/λmin. For κ = 100 that is 0.980 per step, about 690 steps to gain a factor 106. Standardising features brings κ close to 1.
Follow-upDoes scaling matter for tree models? No. For the normal equation? Its answer is unchanged, but conditioning of the solve improves.
TrapStandardising using statistics from the test set (a leakage bug): use the training mean and standard deviation.

Q16.5.11 Use Lagrange multipliers: maximise xy subject to x + y = 10.

AnswerAt an optimum, ∇f = λ∇g: (y, x) = λ(1, 1), so x = y, and with x + y = 10 we get x = y = 5, f = 25.
Follow-upHow does it generalise to inequality constraints? KKT conditions: multipliers are non-negative and zero for inactive constraints (complementary slackness).
TrapForgetting to check that the stationary point is a maximum and not a minimum: compare with the boundary, e.g. (10, 0) gives 0.

Q16.5.12 Show that ridge regression is MAP estimation, and lasso too.

AnswerWith y = Xw + noise (variance σ²) and prior wi ~ N(0, τ²): −log posterior ∝ ‖y − Xw‖²/(2σ²) + ‖w‖²/(2τ²). Multiply by 2σ²: ‖y − Xw‖² + λ‖w‖² with λ = σ²/τ². A Laplace prior with scale b gives the L1 penalty with λ = 2σ²/b.
Follow-upWhat does a larger λ mean for the prior? A tighter prior (smaller τ): stronger belief that weights are near zero.
TrapTreating λ as unrelated to noise level. It is the noise-to-prior variance ratio.

Q16.5.13 What are learning-rate warmup and gradient clipping for?

AnswerWarmup raises the learning rate from near zero over the first steps, because early adaptive-optimizer statistics are noisy and early gradients are large and erratic. Clipping rescales g to g × min(1, c/‖g‖), capping the step but preserving direction, to tame exploding gradients.
Follow-upClip by value or by norm? By norm preserves direction; by value clips each coordinate separately and distorts it.
TrapClipping to hide a bug: a persistently clipped gradient means the model or the data needs attention.

16.6 Probability and Information Theory

Chapter 15 gives the full treatment. Statistical inference lives in the Statistics document; here is the math underneath.

Q16.6.1 What is cross-entropy? Compute it for p = (1, 0, 0) and q = (0.7, 0.2, 0.1).

AnswerH(p, q) = −Σ pi ln qi. For a one-hot p only the true class survives: −ln 0.7 = 0.3567 nats. Using log2 gives 0.5146 bits.
Follow-upHow do cross-entropy, entropy and KL connect? H(p, q) = H(p) + KL(p‖q). With one-hot labels H(p) = 0, so cross-entropy equals KL.
TrapGiving a probability of 0 to the true class: the loss is infinite. Also mixing log bases between code and hand calculation.

Q16.6.2 Define KL divergence. Compute KL(p‖q) and KL(q‖p) for p = (0.5, 0.5), q = (0.9, 0.1).

AnswerKL(p‖q) = Σ pi ln(pi/qi) ≥ 0, zero only if p = q. KL(p‖q) = 0.5 ln(0.5/0.9) + 0.5 ln(0.5/0.1) = 0.5(−0.5878) + 0.5(1.6094) = 0.5108. KL(q‖p) = 0.9 ln 1.8 + 0.1 ln 0.2 = 0.5290 − 0.1609 = 0.3681.
Follow-upWhich direction does maximum likelihood minimise? KL(data‖model). Forward KL is mean-seeking, reverse KL is mode-seeking.
TrapCalling KL a distance. It is asymmetric and violates the triangle inequality.

Q16.6.3 Define entropy. What is the entropy of a fair coin, a fair 8-sided die and a coin with P(heads) = 0.9?

AnswerH = −Σ pi log2 pi bits. Fair coin 1 bit, fair 8-sided die log28 = 3 bits, biased coin −0.9 log20.9 − 0.1 log20.1 = 0.1368 + 0.3322 = 0.469 bits.
Follow-upWhich distribution on n outcomes has maximum entropy? The uniform, with log n.
TrapTreating 0 log 0 as undefined. By convention it is 0, the limit.

Q16.6.4 A disease has prevalence 1%. A test has sensitivity 90% and specificity 95%. P(disease | positive)?

AnswerP(+) = 0.01 × 0.90 + 0.99 × 0.05 = 0.009 + 0.0495 = 0.0585. P(D | +) = 0.009 / 0.0585 = 0.1538, about 15%.
Follow-upWhat does it show? With a low base rate, most positives are false. Use natural frequencies: of 10,000 people, 90 true positives and 495 false positives.
TrapThe base-rate fallacy: answering 90%.

Q16.6.5 Which expectation tricks do you use most?

AnswerLinearity: E[X + Y] = E[X] + E[Y] always, with no independence needed. Indicator variables: count fixed points of a random permutation of n items as the sum of n indicators each with probability 1/n, so the expectation is n × 1/n = 1 for every n.
Follow-upAnother example: expected number of rolls to get a six. Geometric distribution, mean 1/p = 6.
TrapE[XY] = E[X]E[Y] needs uncorrelatedness, and E[1/X] ≠ 1/E[X] (Jensen's inequality for convex functions).

Q16.6.6 Write the variance rules.

AnswerVar(X) = E[X²] − (E[X])². Var(aX + b) = a² Var(X). Var(X + Y) = Var X + Var Y + 2 Cov(X, Y). For n iid terms, the sum has variance nσ² and the mean has variance σ²/n.
Follow-upVariance of X − Y for independent X, Y? Var X + Var Y (variances add, never subtract).
TrapAssuming Var(X + Y) = Var X + Var Y when the variables are correlated.

Q16.6.7 Derive the MLE for a Bernoulli parameter from k successes in n trials.

Answerℓ(p) = k ln p + (n − k) ln(1 − p). Set ℓ' = k/p − (n − k)/(1 − p) = 0, so k(1 − p) = (n − k)p, so p̂ = k/n. ℓ'' < 0 confirms a maximum.
Follow-upWhat does this give for 7 heads in 10? 0.7. What if k = 0? p̂ = 0, which is overconfident; a Beta prior fixes it.
TrapSkipping the second-derivative check, or maximising without noting the boundary cases k = 0 and k = n.

Q16.6.8 What is the MLE of the Gaussian variance? Is it unbiased?

Answerμ̂ = x̄ and σ̂² = (1/n)Σ(xi − x̄)². It is biased: E[σ̂²] = (n − 1)σ²/n. Dividing by n − 1 removes the bias.
Follow-upWhy n − 1? The residuals from the sample mean satisfy one linear constraint (they sum to zero), leaving n − 1 degrees of freedom.
TrapReporting the MLE as "the" variance and being unaware that NumPy divides by n by default, while pandas divides by n − 1.

Q16.6.9 How do MSE and log-loss arise from maximum likelihood?

AnswerIf y = f(x) + ε with ε ~ N(0, σ²), −log likelihood = Σ(y − f)²/(2σ²) + constants, so minimising squared error is MLE. If y ~ Bernoulli(p(x)), −log likelihood = −Σ[y ln p + (1 − y) ln(1 − p)], the log-loss.
Follow-upWhat noise assumption gives absolute error? Laplace noise.
TrapBelieving MSE is chosen "because it is smooth". Its justification is Gaussian noise.

Q16.6.10 Uncorrelated versus independent: give a counterexample.

AnswerIndependent implies uncorrelated, not the reverse. Let X ~ N(0, 1), Y = X². Cov(X, Y) = E[X³] − E[X]E[X²] = 0 − 0 = 0, but Y is a deterministic function of X.
Follow-upWhich measure detects this dependence? Mutual information.
TrapUsing Pearson correlation as a test of independence.

Q16.6.11 Birthday problem: how many people before a shared birthday is more likely than not?

AnswerCompute the complement: P(no match among k) = Πj=0k−1 (365 − j)/365. For k = 23 it is 0.4927, so the chance of a match is 0.5073.
Follow-upWhy so few? There are k(k − 1)/2 = 253 pairs, each with a 1/365 chance.
TrapComputing P(match) directly. Counting "at least one" through the complement is almost always simpler.

Q16.6.12 Monty Hall: should you switch?

AnswerYes. Your first pick wins with probability 1/3. The host's reveal is informed, so the other closed door carries the remaining 2/3. Switching wins 2/3.
Follow-upGeneralise to 100 doors? Host opens 98 losing doors; switching wins 99/100.
TrapSaying 50-50 because two doors remain. The doors are not equally likely, since the host's action depends on your pick.

Q16.6.13 Define mutual information.

AnswerI(X; Y) = Σ p(x, y) ln [p(x, y)/(p(x)p(y))] = KL(joint ‖ product of marginals) = H(X) − H(X|Y). It is zero exactly when X and Y are independent and measures any dependence, not just linear.
Follow-upUse in ML? Feature selection and the information bottleneck.
TrapEquating zero correlation with zero MI; the Y = X² example has zero correlation and positive MI.

Q16.6.14 What is perplexity?

AnswerPerplexity = exp(cross-entropy in nats) = 2cross-entropy in bits: the effective number of equally likely choices. A uniform model over V tokens has perplexity V. Cross-entropy 2.0 nats gives e2 = 7.39.
Follow-upDoes lower perplexity always mean a better model? Only when measured on the same tokenisation and data.
TrapMixing bases: exp of a bits value or 2 to the power of a nats value gives a wrong number.

16.8 Twenty Common Pitfalls

Each pitfall has a wrong way, a right way and a short demo that you can run. All code is deterministic. Many of these are exactly the bugs an interviewer plants in a "find the bug" question.

Pitfall 1: Shape (n,) versus (n, 1)

Wrong: subtract a column vector of predictions from a flat vector of targets and take the mean. NumPy broadcasts to an n×n matrix and returns a plausible but wrong number. Right: make both the same shape first.

import numpy as np
y = np.array([1., 2., 3.]); yhat = np.array([[1.], [2.], [4.]])
print((y - yhat).shape, round(np.mean((y - yhat)**2), 4))      # wrong
print((y - yhat.ravel()).shape, round(np.mean((y - yhat.ravel())**2), 4))  # right

Pitfall 2: Transposing a product

Wrong: (AB)T = ATBT. Right: (AB)T = BTAT; the order reverses. Often the wrong version still has a legal shape, so no error is raised.

16.9 Whiteboard Derivations

Six derivations come up again and again. Learn each as a sequence of lines where every line follows from the previous one by a named rule. Notation: X is n×p (rows are examples), y is n×1, w is p×1.

A. The normal equation

Goal: minimise L(w) = ‖y − Xw‖².

L(w) = (y − Xw)T(y − Xw) = yTy − 2wTXTy + wTXTXw
∇wL = −2XTy + 2XTXw
set ∇wL = 0 ⇒ XTXw = XTy ⇒ ŵ = (XTX)−1XTy (if X has full column rank)
Hessian = 2XTX, positive semi-definite, so the stationary point is a minimum

Geometric reading: XT(y − Xŵ) = 0 says the residual is orthogonal to every column of X. Check with X = [[1, 1], [1, 2], [1, 3]] and y = (1, 2, 2): XTX = [[3, 6], [6, 14]], XTy = (5, 11), det = 42 − 36 = 6, so ŵ = (1/6)(14·5 − 6·11, −6·5 + 3·11) = (4/6, 3/6) = (0.6667, 0.5).

import numpy as np
X = np.array([[1., 1], [1, 2], [1, 3]]); y = np.array([1., 2, 2])
w = np.linalg.solve(X.T @ X, X.T @ y)
print(np.round(w, 4), np.round(X.T @ (y - X @ w), 10))
print(np.round(np.linalg.lstsq(X, y, rcond=None)[0], 4))
[0.6667 0.5   ] [0. 0.]
[0.6667 0.5   ]

B. PCA by Lagrange multipliers

Goal: find the unit direction w that maximises the variance of the projected data. For centred data with covariance matrix Σ, the variance of the projection is wTΣw.

maximise wTΣw subject to wTw = 1
𝓛(w, λ) = wTΣw − λ(wTw − 1)
∇w𝓛 = 2Σw − 2λw = 0 ⇒ Σw = λw
so w is an eigenvector of Σ, and the variance there is wTΣw = λwTw = λ

The variance equals the eigenvalue, so choose the largest. For the next component, add the constraint of orthogonality to the first: the same argument gives the next eigenvector. Example: Σ = [[2, 1], [1, 2]] has λ = 3 with w = (1, 1)/√2 and λ = 1 with w = (1, −1)/√2. Since Σ is symmetric, the eigenvectors are orthogonal. Since Σ = V Λ VT and Σ = XTX/(n − 1) with X = UΣsVT, the same V comes out of the SVD of X (16.3).

import numpy as np
S = np.array([[2., 1.], [1., 2.]])
vals, vecs = np.linalg.eigh(S)
print(vals, np.round(np.abs(vecs[:, 1]), 4))
w = np.array([1., 1.])/np.sqrt(2); print(round(w @ S @ w, 4))
[1. 3.] [0.7071 0.7071]
3.0

C. Logistic regression gradient

Model: pi = σ(zi), zi = w·xi. Negative log-likelihood L = −Σ[yi ln pi + (1 − yi) ln(1 − pi)].

∂Li/∂pi = −yi/pi + (1 − yi)/(1 − pi)
∂pi/∂zi = pi(1 − pi)
∂Li/∂zi = −yi(1 − pi) + (1 − yi)pi = pi − yi
∂zi/∂w = xi ⇒ ∇wL = Σ (pi − yi)xi = XT(p − y)
Hessian H = XTSX with S = diag(pi(1 − pi)) ≥ 0, so L is convex

The Hessian is positive semi-definite for any w, because xTXTSXx = Σ si(xi·x)² ≥ 0. Newton's method on this loss is the classical iteratively reweighted least squares (IRLS) algorithm.

D. The softmax gradient

Let S = Σk ezk and pi = ezi/S. First the Jacobian of softmax.

i = j: ∂pi/∂zi = (eziS − eziezi)/S² = pi(1 − pi)
i ≠ j: ∂pi/∂zj = −eziezj/S² = −pipj
together: ∂pi/∂zj = pi(δij − pj)

Now the loss L = −Σi yi ln pi with y one-hot (or any distribution summing to 1).

∂L/∂zj = −Σi (yi/pi) pi(δij − pj) = −Σi yi(δij − pj)
= −yj + pjΣi yi = pj − yj

The gradient components sum to Σp − Σy = 0, which matches the fact that adding a constant to every logit changes nothing.

E. Bayes' theorem

P(A ∩ B) = P(A | B)P(B) = P(B | A)P(A) (definition of conditional probability, twice)
P(A | B) = P(B | A)P(A) / P(B)
P(B) = Σi P(B | Ai)P(Ai) (law of total probability over a partition Ai)
odds form: P(A | B)/P(¬A | B) = [P(A)/P(¬A)] × [P(B | A)/P(B | ¬A)]

Example from 16.6: prior odds 0.01/0.99 = 1/99, likelihood ratio 0.90/0.05 = 18, posterior odds 18/99 = 0.1818, posterior probability 0.1818/1.1818 = 0.1538. The odds form is the fastest way to update on a test on a whiteboard.

F. Backprop for a linear layer

Forward: Z = XW + 1bT, with X of shape B×din, W of shape din×dout, b of length dout. Suppose the upstream gradient G = ∂L/∂Z (B×dout) is known. Work one entry at a time.

Zbj = Σi XbiWij + bj
∂L/∂Wij = Σb GbjXbi = (XTG)ij ⇒ ∂L/∂W = XTG (din×dout)
∂L/∂bj = Σb Gbj ⇒ ∂L/∂b = column sums of G
∂L/∂Xbi = Σj GbjWij = (GWT)bi ⇒ ∂L/∂X = GWT (B×din)

Shape check: each gradient has the shape of the thing it differentiates, which is the quickest way to detect a misplaced transpose. The sums over b arise because the same W and b are shared by all B examples (the multi-path chain rule).

import numpy as np
rng = np.random.default_rng(5)
B, di, do = 4, 3, 2
X, W, b = rng.normal(size=(B, di)), rng.normal(size=(di, do)), rng.normal(size=do)
T = rng.normal(size=(B, do))
loss = lambda W, b, X: 0.5*np.sum((X @ W + b - T)**2)
G = X @ W + b - T                          # dL/dZ for this loss
gW, gb, gX = X.T @ G, G.sum(0), G @ W.T
def num(f, A, h=1e-6):
    g = np.zeros_like(A)
    for i in np.ndindex(A.shape):
        A[i] += h; up = f(); A[i] -= 2*h; dn = f(); A[i] += h
        g[i] = (up - dn)/(2*h)
    return g
print(np.allclose(gW, num(lambda: loss(W, b, X), W), atol=1e-5),
      np.allclose(gb, num(lambda: loss(W, b, X), b), atol=1e-5),
      np.allclose(gX, num(lambda: loss(W, b, X), X), atol=1e-5))
print(gW.shape, gb.shape, gX.shape)

(3, 2) (2,) (4, 3)
COMMON MISTAKE
Writing ∂L/∂W = G XT or GTX by pattern-matching on the scalar formula. Wrong: shapes B×dout times din×B do not even multiply. Right: XTG is (din×B)(B×dout) = din×dout, the shape of W. Always finish a matrix derivation with a shape check.

Chapter recap

  • Interviews sample your understanding with six formats: concept, calculation, derivation, estimation, debugging and scenario. Answer with the four steps: plain sentence, tiny example, why it matters, limit.
  • Algebra and logs: logs turn products into sums (and underflow into safe numbers), the rule of 72 is ln 2/r corrected, and compounding multiplies factors rather than adding percentages.
  • Linear algebra: rank counts independent directions, det is signed volume, the trace is the sum of eigenvalues, SVD exists for every matrix and PCA is the SVD of centred data.
  • Avoid explicit inverses when solving; use factorisations and watch the condition number κ = σmax/σmin.
  • Calculus: σ' = σ(1 − σ) ≤ 0.25 explains vanishing gradients, and the softmax or sigmoid with cross-entropy both give the clean gradient p − y.
  • Optimisation: gradient descent on a quadratic with curvature a is stable only for η < 2/a; Adam rescales per parameter; L1 gives corners (sparsity), L2 gives smooth shrinkage.
  • Probability: Bayes needs the base rate, expectation is linear without independence, and MLE under Gaussian noise gives MSE while Bernoulli gives log-loss.
  • Information theory: H(p, q) = H(p) + KL(p‖q); KL is asymmetric; perplexity is exp of cross-entropy in nats.
  • Estimation needs a few memorised constants (210 ≈ 1000, ln 2 ≈ 0.693, log102 ≈ 0.301, √2 ≈ 1.414).
  • Most bugs are shape and axis confusion, wrong normalisation, floating-point limits or statistical shortcuts; check with tiny examples, assertions and finite-difference gradients.
  • A steady 75 minutes a day for 12 weeks with spaced repetition and weekly self-tests is enough to reach interview-ready.

Problem 16.12.1 At 9% a year, estimate the doubling time with the rule of 72 and exactly.

Answer: 72/9 = 8 years. Exact: ln 2/ln 1.09 = 0.6931/0.0862 = 8.04 years.

Problem 16.12.2 Compute the cosine similarity of (3, 4) and (4, 3).

Answer: Dot product = 12 + 12 = 24. Norms are 5 and 5. cos = 24/25 = 0.96.

Problem 16.12.3 For L = (wx − y)² with x = 3, w = 2, y = 4, find dL/dw and dL/dx.

Answer: r = wx − y = 2. dL/dw = 2r·x = 2 × 2 × 3 = 12. dL/dx = 2r·w = 2 × 2 × 2 = 8.

Problem 16.12.4 Entropy in bits of the distribution (0.5, 0.25, 0.25).

Answer: 0.5 × 1 + 0.25 × 2 + 0.25 × 2 = 1.5 bits.

Problem 16.12.5 Find the bug: var = sum((x - x.mean())**2) / len(x) is used as the sample variance of 8 points.

Answer: It divides by n, giving the population-style (maximum likelihood) variance. The sample variance divides by n − 1. For the 8 values in Pitfall 3 that is 32/8 = 4.0 versus 32/7 = 4.571. Fix: divide by len(x) − 1, or call np.var(x, ddof=1).

Problem 16.12.6 What does this print? A = np.array([[1, 2], [3, 4]]); print(A.T @ A)

Answer: AT = [[1, 3], [2, 4]]. The product has entries [[1+9, 2+12], [2+12, 4+16]] = [[10, 14], [14, 20]], symmetric, as ATA always is.

Problem 16.12.7 Gradient descent on f = 2x² (so a = 4) uses η = 0.6. Does it converge?

Answer: Update factor 1 − ηa = 1 − 2.4 = −1.4, with magnitude above 1, so it diverges. The threshold is 2/a = 0.5.

Problem 16.12.8 A disease has prevalence 2%, the test sensitivity is 95% and the specificity is 90%. Find P(disease | positive).

Answer: P(+) = 0.02 × 0.95 + 0.98 × 0.10 = 0.019 + 0.098 = 0.117. P(D | +) = 0.019/0.117 = 0.1624, about 16%.

Problem 16.12.9 Show that the softmax cross-entropy gradient p − y sums to zero, and say why that is expected.

Answer: Σ(pj − yj) = 1 − 1 = 0. Softmax is unchanged when a constant is added to every logit, so the loss is constant along that direction and its gradient has no component there.

Problem 16.12.10 Estimate the memory for 50 million vectors of dimension 384 in float32.

Answer: 5 × 107 × 384 × 4 bytes = 7.68 × 1010 bytes, about 77 GB.

Problem 16.12.11 Matrix [[4, 2], [2, 1]]: eigenvalues, rank and one eigenvector.

Answer: Trace 5, det 4 − 4 = 0, so eigenvalues 5 and 0. A zero eigenvalue means rank 1. For λ = 5: A(2, 1) = (8 + 2, 4 + 1) = (10, 5) = 5(2, 1).

Problem 16.12.12 Interview-style: explain L1 versus L2 regularisation to a manager in under a minute.

Answer: Plain sentence: both penalise large weights to prevent overfitting; L1 uses the sum of absolute values, L2 the sum of squares. Example: with a weight of 0.2 and strength 0.25, L1 pushes it to exactly 0 while L2 only shrinks it to 0.13. Why it matters: L1 selects a smaller set of features, L2 keeps all but small. Limit: with correlated features L1 picks one arbitrarily, and the strength must be tuned by validation.
